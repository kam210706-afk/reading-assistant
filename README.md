# Reading Assistant — помощник по чтению

## О проекте

**Reading Assistant** — учебный проект на Python, предназначенный для помощи в организации чтения книг.

**Цель проекта** - создать простого помощника, который позволит пользователю вести список книг, отслеживать прогресс чтения и сохранять заметки.

## Основные возможности

1. Добавление книг в список чтения.
2. Хранение названия книги и автора.
3. Отслеживание статуса чтения.
4. Сохранение заметок о прочитанном.

## Примеры запросов пользователя

**Запрос 1.** Добавление книги

**Запрос пользователя:**

Добавь книгу «Мастер и Маргарита» Михаила Булгакова в мой список чтения и установи статус «Запланирована».

**Ожидаемый результат:**

Агент добавит книгу в список литературы и сохранит следующие данные:

Название: «Мастер и Маргарита».
Автор: Михаил Булгаков.
Статус чтения: «Запланирована».

После выполнения запроса книга должна отображаться в общем списке литературы.

**Запрос 2.** Сохранение заметки о прочитанной книге

**Запрос пользователя:**

Отметь книгу «Преступление и наказание» Фёдора Достоевского как прочитанную и сохрани заметку: «Книга заставляет задуматься о моральной ответственности человека за свои поступки».

**Ожидаемый результат:**

Агент обновит статус книги на «Прочитана» и сохранит заметку, связанную с этой книгой. При последующем просмотре списка литературы пользователь сможет увидеть новый статус и прочитать сохранённую заметку.
