# Reading Assistant — помощник по чтению

## О проекте

**Reading Assistant** — учебный проект на Python, предназначенный для помощи в организации чтения книг.
Приложение позволяет добавлять книги, просматривать список и изменять статус чтения. Данные сохраняются между запусками программы в JSON-файле.

**Цель проекта** - создать простого помощника, который позволит пользователю вести список книг и отслеживать прогресс чтения.

## Основные возможности

1. Добавление книг в список чтения.
2. Хранение названия книги и автора.
3. Отслеживание статуса чтения.
4. Сохранение данных между запусками программы.
5. Просмотр списка доступных команд..

## Примеры запросов пользователя

**Запрос 1.** Добавление книги

**Запрос пользователя:**

Добавь книгу «Мастер и Маргарита» Михаила Булгакова в мой список чтения и установи статус «Запланирована».

**Ожидаемый результат:**

Агент добавит книгу в список литературы и сохранит следующие данные:

Название: «Мастер и Маргарита».
Автор: Михаил Булгаков.
Статус чтения: «Запланирована».

После выполнения запроса книга должна отображаться в общем списке литературы.

**Запрос 2.** Сохранение заметки о прочитанной книге

**Запрос пользователя:**

Отметь книгу «Преступление и наказание» Фёдора Достоевского как прочитанную.

**Ожидаемый результат:**

Агент обновит статус книги на «Прочитана». При последующем просмотре списка литературы пользователь сможет увидеть новый статус.

## Технологии и инструменты

**Компонент**               **Используемый инструмент**
1. Язык программирования   `Python 3.14.7`
2. Система контроля версий `Git`
3. Хостинг репозитория     `GitHub`
4. Проверка качества кода  `Ruff 0.17.3`
5. Среда выполнения        `CPython 3.14.7`
6. IDE и редактор кода     `Visual Studio Code`
7. Терминал                `Git Bash`
8. Менеджер пакетов        `pip`
9. Виртуальное окружение   `venv`
10. Хранение данных        `JSON`

Для работы самого приложения используются только стандартные средства Python. Внешние библиотеки не требуются. Ruff применяется как инструмент разработки для проверки качества и форматирования кода.

Описание файлов:

src/main.py — точка входа и основной цикл приложения.
src/commands.py — обработка пользовательских команд.
src/books.py — операции со списком книг и сохранение данных.
books.json — файл хранения списка книг.
requirements-dev.txt — список инструментов разработки и их версий.
.gitignore — исключение виртуального окружения, кешей и временных файлов.
.github/workflows/ruff.yml — автоматическая проверка кода через GitHub Actions.

## Подготовка окружения

Для работы необходим установленный Python 3 и Git.

Склонируйте репозиторий:

`git clone https://github.com/kam210706-afk/reading-assistant.git`
`cd reading-assistant`

Дополнительные библиотеки для работы приложения не требуются.

## Создание виртуального окружения

Создайте виртуальное окружение:
`python -m venv .venv`

Активируйте его в Git Bash:
`source .venv/Scripts/activate`

После активации в начале строки терминала должно отображаться (.venv).

Для выхода из виртуального окружения используйте:
`deactivate`

## Установка инструментов разработки

Для работы приложения установка дополнительных библиотек не требуется.

Для проверки качества и форматирования кода установите Ruff из файла зависимостей:

`python -m pip install -r requirements-dev.txt`

В файле requirements-dev.txt зафиксирована версия Ruff 0.17.3.

## Запуск программы

Из корневой папки проекта выполните:

`python src/main.py`

## Команды приложения

**Команда**    **Описание**
add        Добавить книгу
list       Показать список книг
status     Изменить статус книги
help       Показать доступные команды
exit       Завершить работу программы

Для каждой книги предусмотрены три статуса:

1. Запланирована
2. Читаю
3. Прочитана

## Хранение данных

Информация о книгах хранится в файле books.json в формате JSON.

При запуске программы данные загружаются из файла. После добавления книги или изменения её статуса информация автоматически сохраняется. Это позволяет сохранить список книг после завершения работы приложения.

## Проверка качества кода

Для проверки синтаксиса Python используется команда:

`python -m compileall src`

Для проверки качества кода с помощью Ruff:

`ruff check src`
`ruff format --check src`
