Reading Assistant — помощник по чтению

Reading Assistant — учебный проект на Python, предназначенный для помощи в организации чтения книг.

Цель проекта: cоздать простого помощника, который позволит пользователю вести список книг, отслеживать прогресс чтения и сохранять заметки.

Основные возможности:
1) Добавление книг в список чтения.
2) Хранение названия книги и автора.
3) Oтслеживание статуса чтения.
4) Сохранение заметок о прочитанном.

Технологии: Python, Git, GitHub

Статус проекта: проект находится на начальном этапе разработки.
